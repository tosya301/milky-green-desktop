# 奶绿 0.7.77 · 用户接入说明

更新日期：2026-10-24。本版提供统一版本号的 macOS Apple Silicon 与 Windows x64 包；Windows 仍为测试版，尚未完成 Windows 实机验收。新增奶白、奶黑、奶小绿女仆装，完善立绘动作、明暗外观及 Windows 音乐接入。

奶绿是桌面伴侣界面。文字聊天连接你自己的 Hermes；麦克风对话还需要你准备本地 ASR；Fish／Qwen 试听可独立使用。应用不附带 Hermes、Python 环境、模型权重、参考录音、API Key 或个人记忆；可选的人设参考随接入资料单独提供，不会自动启用。只想先看角色和界面，可以直接启动；要开始聊天或朗读，按下面对应部分配置。

将应用交给别人时，一并提供 `MilkyGreen-0.7.77-handoff.zip`。其中的 [AGENT-HANDOFF.md](AGENT-HANDOFF.md) 面向协助配置的 Agent，[templates/README.md](templates/README.md) 解释全部示例。不要发送个人 profile 或应用数据目录。

## Agent 兼容范围

奶绿当前内置并验证的是 Hermes 接入。其他 Agent 或模型服务可根据其开放接口开发适配，但本版尚未提供这些适配，不能仅通过替换连接地址直接使用。你可以把接入说明交给自己常用、具备本机操作能力的 AI 助手协助配置；协助者不必是 Hermes。

“协助配置的助手”和“奶绿连接的聊天后端”是两种角色。Pi、Muse、WorkBuddy、Codex、Claude Code 等名称在这里是待评估的适配对象，不是本版已支持清单，也不保证它们都提供相同的开放接口。是否可接，要结合具体产品、版本、接口和实际测试判断。Ollama 提供模型调用接口；它的 OpenAI 兼容接口不能直接替代本版的会话／任务协议。[Ollama 接口说明](https://docs.ollama.com/api/openai-compatibility)

后文可直接执行的聊天接入步骤针对 Hermes。希望保留其他后端的用户，可先让协助者阅读 handoff 的“其他 Agent 的适配开发参考”；这是额外开发路线，不要求先把原有 Agent 改成 Hermes，也不代表本版已经交付桥接工具。

升级前退出旧应用，保留原应用的回退副本，再替换 App 或完整 Windows 运行目录。不要删除或覆盖下面的用户数据目录，不需要重装 Hermes、重新建 profile 或重置现有语音配置。应用会保留已有连接、音色、主题、头像和聊天等设置；新版修改后的配置不保证旧版都能识别，回退时使用升级前由自己保存的备份。

- macOS 应用数据通常位于 `~/Library/Application Support/奶绿/`。
- Windows 应用数据通常位于 `%APPDATA%\奶绿\`。
- “便携 EXE”仍将设置存入当前系统账户的数据目录，不会在退出时自动清除。

新安装默认连接地址为 `http://127.0.0.1:8642`，语音服务默认 Fish，但没有预置 Key 或 Voice ID。也可自行选择 Qwen，或配置本地 VoxCPM2 所需的环境、模型与参考录音。升级保留已有声音选择。

## 2. 角色、头像与配色

“设置 → 桌面立绘 → 当前立绘”提供七个内置角色：**奶绿v4-常服（默认）**、**奶绿v3-白（奶白）**、**奶绿v2-泳装**、**奶绿v2-亚空间（奶黑）**、**奶小绿v1**、**奶小绿v1-常服**、**奶小绿v1-女仆装**。默认奶绿可选半身／全身，其余为半身。各自记忆尺寸；切回默认角色恢复其显示范围。表情、状态、眨眼和实时口型按各自素材能力开放，未制作的选项不可用。切换要等资源准备完成，失败时保留原角色。

奶小绿女仆装支持眼镜开关并记住选择。奶白、奶黑和泳装支持分区头部跟随、呼吸与点击回弹；本版修复这三款点击后没有可见回弹的问题。六个网格立绘待机约 12 fps，交互及活动状态约 30 fps，并完善 WebGL 上下文恢复。立绘尺寸、位置和工具栏适配大尺寸显示。

点击聊天页头像，可选择 PNG、JPEG 或 WebP，拖动裁剪、调整缩放与显示尺寸，再点“保存头像”；“取消”保留已保存状态，“恢复默认头像”可恢复内置图。支持 10 MiB 以内、最多 1600 万像素图片，显示尺寸可调 40–80 px。成功保存的头像与裁剪在重启后保留，本版包含头像首次打开时的恢复修复。

右上调色盘包含 **SAGE MIST、LILAC BLUE、OAT CREAM、BLUSH PINK、NANA7MI** 和 **DIY**。主题即时生效并自动保存；DIY 旁的编辑按钮可修改主背景、卡片与输入框、按钮与强调、正文文字、奶绿的气泡、我的气泡六种颜色，也可选基础配色或生成新的随机配色。六位 HEX 或颜色选择器可自由改色；请自行保持文字可读。DIY 自动保存最近一套，不需要再点设置页保存；关闭编辑框不会撤销已经保存的改动。外观可选浅色、深色或跟随系统，内置及 DIY 配色均同步适配。

名字、签名、头像、界面配色、桌面立绘和 Hermes 的人格／模型彼此独立。选择某个立绘或主题不会替你修改后端身份、语音或记忆。设置里的“立绘版本”表示素材和渲染内容的版本标识，与应用的 0.7.77 版本号不同。

### 自己的 SVG 立绘

点击“选择立绘”，选择本机不超过 16 MiB 的自包含 UTF-8 SVG，等待检查后点“应用立绘”。选择和检查只产生草稿；“取消选择”保留原角色，“恢复默认”回到默认奶绿。应用会保存自己的副本，不改写原文件；之后移动原文件不会让已应用的副本丢失。聊天、审批或语音活动中，请等当前活动结束再应用／恢复。

导入保留比例和透明背景，按可见内容去除底部透明余量。人物部分可拖动，透明处穿透鼠标；受支持的原有轻摇可在“表情与动效 → 动作”调节开关与幅度。仅识别单个外层分组的受限 CSS 平移／旋转循环，其他动画静态显示，不运行 SVG 脚本。自定义 SVG 不自动获得眨眼、表情、视线或说话口型；听得到声音但嘴不动是预期行为。无效、全透明或依赖外部资源的文件不能覆盖当前立绘。

内置角色采用 Mesh 不代表 UI 已支持任意 Mesh、Live2D 或其他模型导入；新增完整动态角色仍需单独开发适配。已识别的既有七海 SVG 内容仍保留问号欢迎图与 NANA7MI 字标联动；主题选择不会触发它，个人 SVG 不随包提供。

## 3. 在线朗读：Fish 与 Qwen

在线服务只负责把文字合成为声音，不改变 Hermes 的聊天模型、人格、记忆或本地识别方式。可先在“设置 → 声音与陪伴”完成独立试听，再配置后面的聊天和麦克风。

### Qwen 在线 · 北京

1. 在自己的[阿里云百炼控制台](https://bailian.console.aliyun.com/)准备华北2（北京）业务空间、对应 API Key，以及可用于 `qwen-audio-3.1-tts-flash` 的系统音色或自己创建的音色 ID。若 Key 限定模型权限，需允许这个合成模型；创建／查询复刻音色还需 `voice-enrollment` 权限。
2. 在奶绿选择“Qwen 在线 · 北京”，填写 `ws-` 开头的 Workspace ID、完整音色 ID 和 API Key，模型保持 `qwen-audio-3.1-tts-flash`。
3. 点“保存并试听”，听到实际声音并显示“试听完成”后，才说明本次真实调用通过。仅显示“已配置”或保存成功，只代表本地字段检查通过。

应用按 Workspace ID 构造北京业务空间专属地址，不需要填写 Base URL。其他地域、OpenAI 兼容 `/compatible-mode/v1` 地址以及旧 `qwen3-tts-vc-*` 音色不能直接套用到这项设置。音色所属业务空间和创建时的合成模型应与这里一致。[Qwen HTTP 接口](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)

### 创建自己的 Qwen 音色

本版没有在应用内上传参考音频或创建云端音色的界面。先按官方[声音复刻指南](https://help.aliyun.com/zh/model-studio/voice-cloning-user-guide)中的 **Qwen-Audio-TTS** 流程，在自己账号下准备有权使用的清晰单人录音、创建音色并确认可用，再将返回的 `voice_id` 填入奶绿。目标模型必须是 `qwen-audio-3.1-tts-flash`；仅编辑 ID 字符串不会创建新声音。

有 Agent 协助时，可直接交给它阅读 [AGENT-HANDOFF.md](AGENT-HANDOFF.md) 的 Qwen 复刻参数和私有临时上传步骤。账号、Key、Workspace、参考录音和生成的自定义音色全部使用你自己的；公共包不含开发者的声音记录。

本地音色列表只保存 ID，不是离线模型。云端音色的可用性、保存期限、调用费用和免费额度由服务提供方及你的账号决定；不要把“已保存”理解为永久免费或永久在线。使用前以[百炼价格页面](https://help.aliyun.com/zh/model-studio/model-pricing)及控制台为准。

### Fish Audio 在线

选择“Fish Audio 在线”，填自己的 API Key、32 位小写十六进制 Voice ID（不是网页链接），再选 `s2.1-pro-free`、`s2.1-pro` 或 `drama-3`，点“保存并试听”。应用显式使用所选模型，不因失败自动切换到另一个服务或付费模型。额度、权限和计费以自己的 Fish 账号为准。[Fish 官方 TTS 参数](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech)

### 音色列表与密钥

- 音色栏**单击下拉选择、双击原位输入完整 ID**；也可点“输入 ID”或“添加音色…”。列表只显示 ID，没有音色名称或重命名栏。
- 点击别处或按 Tab 离开输入框，会恢复下拉并保留本次 ID 草稿，标为“待保存”。点“保存语音设置”或“保存并试听”成功保存后才收录到本地列表；Enter 保存，Escape 还原本次进入编辑前的 ID。保存失败保留草稿。
- Qwen 列表按 **Workspace ID + 模型** 隔离；切换空间不会带入另一个空间的音色。Fish 与 Qwen 独立，Fish 三个模型共用其音色列表。重复保存不新增重复项；每个服务最多 100 条，达到上限会提示。
- 原有当前音色会迁入列表，成功保存的选择在重启后保留。换音色只影响后续新合成，已有消息回放使用已完成的原录音。
- Fish 和 Qwen Key 分开保存在本机系统账户加密存储中；成功保存后输入框清空，显示已加密保存，以后留空保留。不要把 Key 放入模板、截图或聊天。换机器／账户应重新填写，不直接复制加密文件。

试听和朗读会将待合成文字发送给所选在线服务；本地配置检查不请求远端。停止试听只终止当前播放／请求，不代表已发生的服务用量会退回。遇到音色库损坏提示时保留原设置和数据，让协助者检查；不要清空整个应用目录来绕过错误。

## 4. 先确定地址、profile 与认证目录

确认现有 Hermes 自身能正常对话；记录你要连接的 profile ID。中文显示名可以任意，profile ID 则使用 Hermes 的规范名称：1–64 位，首位为小写字母或数字，其余可用小写字母、数字、`_`、`-`。`default` 对应根 Hermes home，不是 `profiles/default`。[官方 Profiles 指南](https://hermes-agent.nousresearch.com/docs/user-guide/profiles)

在“Agent 连接”同时设置地址与配置文件夹，二者必须指向同一个 agent：

| 实际网关方式 | 本地 Agent 地址示例 | 应选择的配置文件夹／认证来源 |
| --- | --- | --- |
| 默认 profile 的监听器 | `http://127.0.0.1:8642` | 根 Hermes home |
| 命名 profile 的既有独立监听器 | `http://127.0.0.1:9001` | `HERMES_ROOT/profiles/research` |
| 共享网关服务命名 profile | `http://127.0.0.1:8642/p/research` | `HERMES_ROOT/profiles/research` |
| 共享网关的默认路由 | `http://127.0.0.1:8642/p/default` | 根 Hermes home |

端口是例子，应沿用实际监听端口。地址是 API 根地址，**不加 `/v1`、`/v1/chat/completions` 或网页 dashboard 路径**。本版只接受本机 HTTP 回环地址和可选 `/p/<profile>` 前缀；不支持远程 IP、URL 内密码、查询参数或片段。

留空配置文件夹时，应用按地址里的 profile 推导本机默认目录；无前缀地址推导根 home。因此独立端口上的命名 profile、WSL、自定义数据目录必须明确选择其实际文件夹。应用只能看到自身启动环境中的 `HERMES_HOME`，不能依靠另一个终端临时设置的变量。

| 环境 | 根 Hermes home 示例 | 命名 profile 示例 |
| --- | --- | --- |
| macOS | `~/.hermes` | `~/.hermes/profiles/research` |
| Windows 原生 | `%LOCALAPPDATA%\hermes` | 上述目录下的 `profiles\research` |
| Windows 旧目录 | `%USERPROFILE%\.hermes` | 上述目录下的 `profiles\research` |
| Windows 应用连接 WSL | `wslpath -w "$HOME/.hermes"` 输出的 UNC 路径 | 上述目录下的 `profiles\research` |

表中 `~` 和环境变量只用于定位目录；用文件夹选择器选择后，路径字段应显示完整实际路径，不填 `%LOCALAPPDATA%`、`~` 或模板占位文字；也不要选 Hermes 代码仓库、虚拟环境或模型目录。Windows 原生和 WSL 可以共存，选择已有环境即可。[Windows 原生目录](https://hermes-agent.nousresearch.com/docs/user-guide/windows-native)、[WSL2 指南](https://hermes-agent.nousresearch.com/docs/user-guide/windows-wsl-quickstart)

奶绿先从**所选目录**的 `.env` 读 `API_SERVER_KEY`；没有该项时，支持该目录 `config.yaml` 中的 `gateway.api_server.key`、`gateway.platforms.api_server.key` 或 `platforms.api_server.key`。重复／冲突值会报错，不会向父 profile 借用密钥。已有有效配置不用改写为 `.env`。共享命名路由必须使用目标 profile 自己的 Key，不能复用根默认 profile 的 Key。[Hermes API 认证](https://hermes-agent.nousresearch.com/docs/user-guide/features/api-server#authentication)

## 5. 可选 API 配置工具

已有 API 可用，直接跳到下一节。另附 `tools/setup-hermes-api.py` 只帮助**已有 profile**补齐缺少的回环监听变量或 Key；需要 Python 3.8+ 标准库，不安装依赖、不创建 profile、不修改模型／人设／工具权限，不改 `multiplex_profiles` 或 `standalone`，也不启停网关。

先选择与现有网关一致的方式，运行预览。确认输出目录和端口符合预期后，在**同一命令末尾**加 `--apply` 才写入。`--hermes-home` 总是根 Hermes 数据目录，`--profile` 是规范 ID。下面命令从交付目录运行：

```bash
# macOS 或 WSL：默认 profile，根监听器
python3 tools/setup-hermes-api.py --hermes-home "$HOME/.hermes" --profile default --mode direct

# 已有独立网关上的 research：只处理该 profile，端口按实际情况调整
python3 tools/setup-hermes-api.py --hermes-home "$HOME/.hermes" --profile research --mode direct --port 9001

# 已有共享网关：处理默认监听配置和 research 自己的认证 Key
python3 tools/setup-hermes-api.py --hermes-home "$HOME/.hermes" --profile research --mode shared --port 8642
```

Windows 原生在 PowerShell 中运行相同工具，例如：

```powershell
py .\tools\setup-hermes-api.py --hermes-home "$env:LOCALAPPDATA\hermes" --profile default --mode direct
```

WSL Hermes 的工具应在 WSL 终端运行，传 Linux 路径；不要让 Windows Python 通过 UNC 改写 Linux 配置。`--mode direct` 是默认值。`--port` 省略时保留已有端口；没有已有端口的默认／共享监听器采用 8642，新的独立命名 profile 要显式提供端口。

工具要求每个待处理 profile 已有 `config.yaml`，不会把空目录当成安装完成的 agent。工具不会覆盖已有 Key 或冲突端口；写入前检查全部涉及文件，旧 `.env` 留同目录 `.env.before-milky-*` 备份。保留原注释、换行与无关字段；普通写入失败会尽力回滚已写文件；若同时有人修改配置，会保留并发修改并报告人工核对。POSIX 新文件仅当前用户可读写，Windows 使用目录继承的 ACL。不要同时让其他工具改同一配置。

发现既有 YAML API 设置、含歧义的 `.env` 语法、链接／重解析目录或失效 profile 时，工具会停止，保留原状。工具的保守检查比应用读取更严格；这种情况按现有 Hermes 配置人工核对即可，不要删旧 Key 强行重跑。工具没有联网验证，也没有保证网关已经启动。

独立监听器继续按其现有服务方式运行。共享网关必须实际服务目标 profile；用 `hermes -p default gateway status` 检查，命名 profile 不得处于已暂停／独立服务状态。**无需为了奶绿把可用的独立网关迁移成共享模式。** 只有选共享路由时才依赖 `gateway.multiplex_profiles`；共享路由应以当前服务状态确认，具体迁移和冲突按 [官方共享网关指南](https://hermes-agent.nousresearch.com/docs/user-guide/multi-profile-gateways)处理，不复制一个强制开关覆盖现有拓扑。需要重载配置时，由现有网关所属环境按其服务方式重启原实例。确无既有网关、且准备启动默认 profile 时，可按当前 Hermes 的帮助在前台运行 `hermes -p default gateway`；保持终端运行，再测试连接。不要同时执行前台启动和已有后台服务启动。

## 6. 文字连接与 WSL 检查

点击“保存并测试连接”。应用要求 Hermes 的 `/v1/capabilities` 声明 `platform: hermes-agent`、`run_status` 和 `run_events_sse`；实际聊天还使用 `/api/sessions`、`/v1/runs`、任务事件与停止接口。普通 OpenAI 兼容聊天端点不能代替这些接口。[Hermes capabilities 和 Runs API](https://hermes-agent.nousresearch.com/docs/user-guide/features/api-server#runs-api-streaming-friendly-alternative)

连接成功后发一条简短文字，确认完整回复，再开始新会话并重开应用检查会话行为。更换地址或 profile 后会重建后端会话；面板已有显示记录保留，新 profile 从新的后端会话开始。连接身份可读取该 profile 的显示元数据；聊天显示名与签名由奶绿本地设置控制，不替换后端人设；模型与思考强度沿用 Hermes 当前设置。连通检测通过但运行报错时，应检查所选 Hermes 的模型、工具与网关状态，不要复制其他 profile 的配置。

Windows 连接 WSL 时：PowerShell 用 `wsl --list --verbose` 查看发行版；对应 WSL 终端用 `wslpath -w "$HOME/.hermes"` 或目标 profile 路径取得 UNC 写法。Windows 到 WSL 通常可用回环地址；若失败，先确认发行版和网关运行，再检查 localhost 转发。[Microsoft WSL 网络说明](https://learn.microsoft.com/en-us/windows/wsl/networking)

`Test-NetConnection 127.0.0.1 -Port 8642` 只验证端口，不验证 Key 或 API 能力。不要把 WSL 的 `172.x` 地址填入本版。WSL 本地语音桥接还依赖默认 `/mnt/c` 等自动挂载；关闭自动挂载或自定义 mount root 时要先调整环境。[WSL automount 设置](https://learn.microsoft.com/en-us/windows/wsl/wsl-config#automount-settings)

## 7. 可选本地朗读与麦克风识别

本地模型与 Python 环境由你准备。模板位于 `templates/voice/`，只复制需要的配置到**所选 profile**的 `voice/` 目录；默认 profile 则使用根 home 下的 `voice/`。先替换所有路径，再保存为对应正式文件名。不要覆盖已有可用语音配置。

**VoxCPM2：** `voxcpm2.example.json` 对应 `voice/voxcpm2.json`，`backend: "builtin"` 使用应用内附 worker。需要你自己的 Python、完整本地 VoxCPM2 模型目录和有权使用的 60 秒以内 PCM WAV（单／双声道）参考音频；模型与音频不随包。字段为 `python`、`model_dir`、`reference`、`device`，以及分段上限和推理选项。新公共后端不依赖个人 profile 脚本或控制提示文件。

**ASR：** 选择一个模板保存为 `voice/asr.json`。SenseVoice 为 `provider: "sensevoice"`；Nano 为 `provider: "fun-asr-nano"`，必须是 **Fun-ASR-Nano-2512-hf 的 Transformers 格式检查点**，不是同名的原始格式。路径字段是 `modelPath`，与 TTS 的 `model_dir` 不同。ASR 是麦克风功能所需，文字聊天和 Fish／Qwen 试听不依赖它。

先用 `device: "cpu"`。TTS 可按实际 PyTorch 支持改为 `cuda`／`cuda:N`，macOS 才可用 `mps`；ASR SenseVoice 使用 CPU，Nano 可用 CPU 或 macOS MPS。Windows JSON 路径中的反斜杠写成 `\\`；WSL 配置中的 Python、模型和参考音频用 Linux 绝对路径，应用的 profile 字段则用 Windows UNC 路径。

麦克风对话还要求 Hermes 已连接、自动播放回复语音已开启、安静模式已关闭，系统允许桌面应用使用麦克风。先验证 ASR 识别，再验证一轮识别→回复→朗读与停止。依赖安装、模型准备和离线预检细节见 `AGENT-HANDOFF.md`。

## 8. 一起听：Spotify 与网易云

### Spotify

Spotify 沿用奶绿当前选中 Hermes profile 的插件和授权。兼容旧版内置客户端及新版独立插件；更新奶绿不会替你安装插件或登录账号。先在 Spotify 桌面客户端播放一首歌，并在设备列表选中这台电脑。应用不会自动转移手机或音箱上的播放；播放控制还受 Spotify Premium、开发者应用和账号权限限制。

新版 Hermes 可在安装 Hermes 的终端执行下面命令。把 `<profile>` 换成奶绿当前使用的名称；默认 profile 可省略 `-p <profile>`。先查询，缺失时再安装或登录：

```text
hermes -p <profile> spotify status
hermes -p <profile> plugins install spotify
hermes -p <profile> spotify login
```

旧版 Hermes 可能使用 `hermes auth spotify`。以实际版本的帮助和 [Hermes Spotify 文档](https://hermes-agent.nousresearch.com/docs/user-guide/features/spotify) 为准。登录向导要求的回调地址应与自己的开发者应用完全一致。开发模式账号名单及 Premium 要求见 [Spotify 说明](https://developer.spotify.com/documentation/web-api/concepts/quota-modes)。

Windows 原生安装可选择 `%LOCALAPPDATA%\hermes` 或实际旧安装根下的 profile。0.7.77 补充新版共享安装、当前 Python 环境、封装 Python 入口和中文路径兼容。WSL 环境在 Windows 应用中选择对应 `\\wsl.localhost\发行版\home\用户名\.hermes` 下的 profile，Hermes 命令在同一 WSL 发行版中运行，Spotify 桌面客户端仍在 Windows 播放。文件夹字段填写选择器返回的完整路径，不直接填环境变量或 Linux 路径。

### 网易云音乐

**macOS：** 从网易云客户端的本地播放记录读取歌曲和进度，线上获取匹配歌词；不读取账号凭据。首次点击“允许播放控制”时申请辅助功能权限，用于操作网易云菜单。支持可识别的播放／暂停、上下首、随机和循环模式；读取不到可靠模式时禁用相关按钮。调节进度和音量仍在网易云客户端操作。由旧公开版升级后，若原有辅助功能许可失效，请在系统设置中移除旧条目并重新添加当前 App。

**Windows（测试版）：** 需要 Windows 10 1809+／Windows 11、系统 Windows PowerShell 5.1，以及会公开系统媒体会话的网易云客户端。若客户端提供系统媒体控制相关选项，先开启，重启客户端并播放一首歌，再打开奶绿“一起听”。无需给奶绿登录网易云账号或安装 Hermes 网易云插件。

Windows 通过 SMTC 读取歌曲和状态，按钮按客户端实际提供的能力开放：播放／暂停、上下首，以及可能提供的进度、随机和循环。多个网易云会话同时匹配时不猜目标。部分版本不给时间轴：此时保留歌曲和可用按钮，进度显示 `--:--`，暂停同步歌词；不能据此判断为整体连接失败。暂无 Windows 网易云 SMTC 封面读取，可能显示占位封面；音量在播放器调整。

### 歌词与问题排查

两者同时播放时当前优先网易云；切换来源前暂停不想跟随的播放器。歌词需匹配到歌曲；可靠字时间可用时逐字同步，否则逐句。Windows 网易云还需要可靠时间轴，匹配不唯一时不猜录音版本。歌词服务、客户端版本和网络会影响可用性。

“一起听”底部的错误信息与“连接帮助”可区分插件、授权、设备和系统会话问题，修复后点“重试”。聊天里“播放某首歌”由 Agent 自己的工具处理，需要单独配置和验证，并不由“一起听”按钮接入自动提供。Windows 真实网易云、Spotify 授权和播放仍等待实机验收。具体验收顺序见 [Windows 测试说明](Windows测试说明.md)。

桌面歌词保留独立透明舞台和现有歌词效果；开启后按实际界面调整效果与位置。

### macOS 语音收音

macOS 14+ 可在“语音收音”中启用“说话时降低音乐”。它只在你启动语音对话时使用 Apple 原生收音、回声处理和背景声音降低；你或奶绿说话时背景声音变轻，安静后回升，结束对话后释放。可能影响所有其他音频，实际曲线与听感取决于系统和设备；不承诺消除所有歌声或保持原输出听感。

关闭时使用普通收音。macOS 13 会提示不支持此项，应用整体仍可运行。Windows 本版隐藏整个“语音收音”区域，迁移了开启状态也不会调用 Apple 组件；这不删除 Windows 的普通麦克风对话能力。

## 10. 常见失败与完成检查

| 现象 | 先检查 |
| --- | --- |
| 连接超时／拒绝 | 实际监听端口、原网关是否运行；WSL 再查回环转发 |
| Hermes 401／404 | API 地址与认证目录是否属于同一 profile，是否误加 `/v1`，共享路由是否实际服务该 profile |
| 不支持任务接口 | 目标是否为提供 Sessions／Runs 能力的 Hermes，不能用通用 OpenAI 兼容端点代替 |
| Qwen 认证或音色失败 | 北京地域、Workspace、Key 模型授权、完整 ID 和相同 `target_model`；不自动回退 Fish |
| Fish 401／402／429 | Key、账号权限／额度、限流与网络，先保留选定模型排查 |
| 在线已配置但无声 | “已配置”不是远端验证；检查输出设备、应用音量及一次真实试听结果 |
| helper 拒绝修改 | 按报告核对旧 YAML／端口／语法，保留旧文件；不要删 Key 强行重跑 |
| 本地语音不可用 | 当前 profile 的路径、Python 依赖、模型格式和设备支持；WSL 再查挂载 |
| SVG 不摇或嘴不动 | 受限轻摇未识别时静态显示；自定义 SVG 没有自动口型 |
| 音色库提示损坏 | 保留原数据，请协助者检查格式；不要重置其他配置或聊天 |
| 一起听不可用 | 播放器是否在本机播放、同 profile 授权、平台支持和显示出的能力／权限 |

建议按所需功能完成：启动／托盘 → 角色切换、拖动／缩放 → 头像和 DIY 保存并重启 → 一次在线试听／停止 → Hermes 一轮短文字回复 → 可选本地 TTS／ASR → 可选一起听与 macOS 降音乐。只启用了部分功能，就只记录那些实际通过的部分。

本版最终包体检查、回归及宿主验收范围由随附发布说明、manifest 和验收记录列明。旧版记录或个人电脑上的已配置环境不能替代你在目标机器的验收。
