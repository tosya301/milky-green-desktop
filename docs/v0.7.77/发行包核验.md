# 奶绿 0.7.77 发行包核验

核验日期：2026-10-24。Mac Apple Silicon 与 Windows x64 的版本号均为 0.7.77；Windows 仍为测试版。

## 归档与源码一致性

两平台共 **10,799 个运行文件**逐项哈希相同，共同来源文件 **10,795 个**也一致。原生辅助程序与 Electron 平台文件分别构建。所有应用归档重新核对字节数和 SHA-256，并通过各自的 ASAR 白名单、敏感内容扫描、架构和归档往返检查。

Mac 为持久本地证书签名，非 Apple Developer ID，未公证；Windows 未附发行者签名。构建清单中的 `hostRuntime: false`／`windowsRuntime: false` 表示构建时未运行目标宿主；下述独立运行检查另记于 [verification.json](verification.json)，没有把构建清单事后改写为实测结果。

## 实际完成的检查

- Node 源码完整回归：1332 通过、0 失败、6 跳过；Python：44 通过、0 失败。
- 随后新增 PowerShell 竞态契约用例，Windows 网易云最终定向套件：16 通过。完整回归统计与这个定向结果分别记录，不混算为一轮全量测试。
- Mac 最终签名包：**65 项检查通过**，使用真实打包 Electron 和独立配置，验证奶白、奶黑、泳装的压下／回弹／复位、连点、关闭动效、减少动态效果、拖动不触发点击，以及上下文恢复后的响应。三个录像的时序抽帧已查看。
- Mac 验收用受控指针和隔离服务，不读取个人配置、不占用个人快捷键；没有重新测试所有云服务、麦克风、实体鼠标延迟或所有显示设备。
- Windows：x64 EXE、完整目录 ZIP 的包体与回解一致性通过；包内实际 JavaScript 在 macOS 浏览器配合 SMTC 模拟状态，验证歌曲、缺失／恢复时间轴、暂停和连接帮助。
- PowerShell 解析、WinRT 反射接口与竞态夹具在 macOS PowerShell 7.5.4 验证；**不等于 Windows PowerShell 5.1／真实 WinRT 实测**。
- 角色卡 V2 JSON 可解析，PNG 内嵌内容与其一致；改动仅涉及声明和资料版本，原 PNG 图像数据保持一致。配置模板 JSON、接入链接及归档内容另作检查。
- VoxCPM2 指南已按现行代码核对，介绍已实现措施和参数建议；本次未新增硬件速度基准，也没有修改用户保存的语音配置。

## 仍待目标机器确认

Windows 实机启动、原生鼠标／DPI 行为、真实网易云 SMTC 字段及控制、Spotify 实际授权与播放、GPU 语音环境和声卡。不同网易云版本可能不提供时间轴、封面或部分能力。具体步骤见 [Windows测试说明](Windows测试说明.md)。

用户账号、设备、网络和模型环境各不相同，按自己选用的功能验收；模拟后端、文件哈希和编译成功不能替代真实调用。
