# 明前奶绿 · 可选角色参考资料

这是一份第三方根据公开资料整理的非官方粉丝向角色卡，包含角色形象、花店世界观、说话风格、粉丝梗和编写的对话示例，供配置 Agent 时参考、取舍。它不代表本人或运营方，也不代表示例对话中的事件真实发生。原有日期来源索引保留，未逐条独立核验。

- [Markdown 角色资料](明前奶绿_公共版角色卡.md)：适合阅读，或按需将人物设定和口吻加入自己 Agent 的角色配置。
- [Character Card V2 JSON](明前奶绿_公共版_chara_card_v2.json)：供支持该格式的前端使用。
- [Character Card V2 PNG](明前奶绿_公共版_chara_card_v2.png)：图片内嵌同一份角色数据，导入方式取决于对应前端。

奶绿 App 0.7.77 不提供角色卡导入或自动加载功能。使用这些资料由你自行选择，不会改变 App 的默认配置。为现有 Agent 添加人设时，只合并需要的角色内容，保留原有模型、记忆、工具权限与工作规则；不要用整张卡覆盖完整系统配置。

公开分享请保留卡内的非官方说明及使用边界。资料及图片的公开提供不构成额外的角色、图像或声音授权；项目说明见 [NOTICE.md](../NOTICE.md)。

随 0.7.77 收录的资料版本为 v1.0.1：统一删除原稿中一概禁止语音／声音合成的表述；其余人物内容、来源索引及非官方说明保留。PNG 仅更新内嵌角色数据，图像像素不变。
