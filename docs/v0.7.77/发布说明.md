# 奶绿 0.7.77 发布说明

发布日期：2026-10-24。相比上一公开版本 **0.7.49**，本次汇总近期更新，Mac Apple Silicon 与 Windows x64 统一为 **0.7.77**。**Windows 仍为测试版，等待实机验证。**

- **三款新增立绘：** 奶白、奶黑和奶小绿女仆装加入原有角色，内置角色共七款；女仆装支持可保存的眼镜开关。
- **立绘动作与细节：** 奶白、奶黑、泳装支持头部跟随与身体分区呼吸；补上三款点击后的压下、回弹和复位。完善表情、单眨、常服思索／猫嘴，以及眼睫与局部接缝显示。
- **显示与性能：** 六个网格角色采用待机约 12 fps、活动约 30 fps 调度；改善上下文恢复、角色切换和拖动跟随。完善大尺寸立绘、按角色保存尺寸、工具栏与气泡布局。
- **浅色、深色与跟随系统：** 内置主题及 DIY 配色适配明暗模式；DIY 可持续生成新的六色随机搭配，并从当前主题继续编辑。
- **Windows 网易云接入：** 通过系统媒体会话读取歌曲与播放状态，按实际能力提供控制。需要 Windows 10 1809+ 和支持 SMTC 的网易云版本；没有时间轴时保留歌曲与按钮，进度显示 `--:--`，暂停同步歌词。当前没有 SMTC 封面读取。
- **Spotify 兼容改善：** 适配新版 Hermes 独立 Spotify 插件、Windows 安装目录、当前及封装 Python 环境、UTF-8 BOM 和中文分块输出。沿用当前 profile 授权，本机播放控制仍受 Spotify 账号和设备条件限制。
- **Mac 网易云与使用细节：** 改善随机／循环模式读取与切换；完善音乐按需加载、歌词舞台恢复、隐藏立绘时的任务继续和快捷键失败提示。
- **语音：** Fish Audio 新增 Drama 3；完善麦克风错误提示。已有声音选择保留；Qwen 继续使用北京 Flash 模型，不含 Next。
- **接入资料与可选角色卡：** 更新用户说明、Agent handoff、Windows 测试说明及 [VoxCPM2 性能优化指南](VoxCPM2性能优化指南.md)；随包提供第三方整理的公开角色参考（Markdown、Character Card V2 JSON／PNG）。由用户自行选择使用，不自动加载、不新增 App 导入功能。

## 下载与升级

Mac 使用 `MilkyGreen-0.7.77-macos-arm64.app.zip`；Windows x64 在便携 EXE 和完整目录 ZIP 中选一种。两平台共用 `MilkyGreen-0.7.77-handoff.zip`。先退出旧版、保留自己的备份后替换程序，保留用户数据目录。应用包不包含个人账号、Key、音色、参考录音、聊天、Hermes、Python 环境或模型。

Mac 使用持久本地证书签名，未获得 Apple Developer ID 签名或公证；由旧公开版升级时，系统可能要求重新给予辅助功能许可。Windows 未附发行者签名。系统来源提示与音乐客户端权限应按实际环境处理。

## 使用条件与验证范围

“一起听”按钮接入与 Agent 聊天点歌是不同功能；后者仍需 Agent 的工具支持。本版不承诺任意网易云版本均提供时间轴或全部按钮。Spotify 需要当前 Hermes profile 的插件、授权及唯一可识别的本机播放设备，App 不替用户安装或登录。

源码 Node 全量回归 1332 通过、6 跳过，Python 44 通过；新增 PowerShell 契约用例后 Windows 网易云定向套件 16 通过。Mac 最终包的隔离宿主检查和 Windows 包体／模拟界面检查详见 [发行包核验](发行包核验.md)。Windows 实机、真实音乐账号和所有语音设备没有在本次发布中完成全面验证。
