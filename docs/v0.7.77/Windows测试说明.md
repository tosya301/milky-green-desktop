# Windows 0.7.77 测试说明

Windows x64 仍是测试版。已完成包体、模拟状态界面及自动回归检查，尚未在 Windows 实机验证 PowerShell 5.1／WinRT、网易云客户端及 Spotify 实际授权播放。请记录 Windows 和播放器的具体版本。

## 启动与升级

便携 EXE 与完整目录 ZIP 二选一。目录 ZIP 需完整解压，运行其中 MilkyGreen.exe。升级前退出旧应用并保留备份，保留 `%APPDATA%\奶绿` 用户数据；不要把“便携”理解为设置自动写在 EXE 旁边。已有声音与 Agent 设置继续使用，不需重置。

## 网易云音乐

1. 使用 Windows 10 1809+ 或 Windows 11，确认系统 Windows PowerShell 5.1 可用。
2. 在网易云中开启其版本提供的系统媒体控制选项（若有），重启客户端并播放歌曲。先暂停其他播放器，保留一个网易云实例。
3. 打开奶绿“一起听”，确认曲名、歌手和播放状态。若找不到会话，查看“连接帮助”；客户端未向系统提供 SMTC 时，本版无法凭空接入。
4. 依次测试当前可用的暂停、继续、下一首、上一首；每次核对播放器实际结果。随机、循环和拖进度仅在对应能力开放时测试，灰色按钮无需强行启用。
5. 有有效时间轴时检查进度和可匹配歌词；若进度为 `--:--`，记录为“客户端未提供可靠时间轴”，此时歌曲和可用控制应仍工作，不应出现伪造进度或同步歌词。
6. 切歌、关闭／重开网易云后重试，确认没有控制错误播放器或重复跳歌。Windows 网易云当前可能显示占位封面，音量在网易云中调整。

网易云接入无需给奶绿登录网易云账号或配置 Hermes 插件，依赖的是本机系统媒体会话。不同客户端版本能力可能不同。

## Spotify

1. 奶绿选择当前已授权的 Hermes profile。原生 Windows 与 WSL 分别沿用自己环境的插件和 Python；不混用不同 profile 的授权。
2. 新版 Hermes 先执行对应 profile 的 `spotify status`；插件或授权缺失时才运行 `plugins install spotify`／`spotify login`。命令写法见用户说明。
3. 在 Windows Spotify 桌面客户端播放，设备列表选择本机。播放控制需满足 Spotify 账号和开发者应用要求。
4. 检查曲名、播放状态、歌词、暂停／继续及切歌，留意中文路径和曲名显示；不会自动把手机或音箱上的播放转移过来。

## 反馈

记录系统版本、奶绿版本、播放器版本、Hermes 原生／WSL 类型、失败步骤和界面错误即可。不要上传 `.env`、`auth.json`、访问／刷新令牌、完整 profile 或私人聊天。
