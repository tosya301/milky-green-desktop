## 从 v0.7.4 到 v0.7.49

- **内置立绘与全身显示。** 默认奶绿v4-常服支持半身／全身，新增奶绿v2-泳装、奶小绿v1、奶小绿v1-常服，分别记忆尺寸；其他三套当前为半身。表情与动作按各自素材能力开放。
- **默认立绘精修。** 调整发丝、衣纹与遮挡细节，增加向下视线范围，发梢和蝴蝶结垂带随头部动作产生惯性与回弹；保留现有眨眼、表情与实时语音口型。
- **动画性能。** 减少重复路径写入、格式化计算及眼部重复绘制。各设备、窗口尺寸和动作强度仍影响表现，不承诺固定帧率或统一性能提升幅度。
- **DIY 配色。** 在原有五套预设外新增 DIY，六色可自由编辑，36 组随机搭配可继续修改，自动保存并在重启后恢复；切换预设不覆盖 DIY。
- **头像首显修复。** 等保存的头像和裁剪结果准备好再显示聊天窗口，修复重开时先闪默认图、再跳回自定义头像的问题。头像上传与裁剪本身是原有功能。
- **一起听与歌词舞台。** 新增集中展示 Spotify 当前歌曲、封面及播放控制的面板，17 种歌词效果、透明穿透桌面舞台、位置调整与同步微调。旧版已有通过 Agent 控制 Spotify 的能力，本次新增的是面板与舞台。
- **网易云实验性接入。** macOS 可读取客户端当前歌曲、封面与歌词，按可用权限提供部分控制；进度拖动、绝对音量等尚未开放，完整度不与 Spotify 等同。
- **真实逐字歌词。** 可靠字时间可用时按真实逐字时间显示；缺少时保持逐句，不用估算冒充真实同步。修复网易云整数秒进度造成的时钟回跳，并补充严格匹配的字时间来源；这不代表接入 QQ 音乐播放器。
- **Qwen 北京在线语音。** 支持 `qwen-audio-3.1-tts-flash`，填写自己的 Workspace、API Key 和匹配音色后保存、试听；保留 Fish Audio 与本地 VoxCPM2。复刻在应用外按百炼官方流程完成，应用内没有上传／创建音色界面。
- **音色 ID 列表。** Fish／Qwen 可单击选择、双击原位输入，失焦回下拉并保留草稿，成功保存才收录。列表只显示 ID，不含名称／重命名栏；Qwen 按业务空间和模型隔离。换音色不改已有录音，密钥分别加密保存。
- **说话时降低音乐。** macOS 14+ 可在语音对话时使用 Apple 原生语音处理：说话或回复时背景声降低，安静后回升。系统处理可能改变回复听感，也可能影响其他系统音频；不承诺适配所有设备。
- **连续语音中断修复。** 有效回复中的轮次标记不匹配时，正文仍正常显示、朗读，过期的结束指令不执行；不完整或非协议输出仍明确报错，不宣称所有中断问题已解决。
- **Windows 与输入界面。** Windows 按同一份 0.7.49 源码重新打包，隐藏整个 Apple 专属“语音收音”区域，普通语音入口保留。本地 Agent 地址与配置文件夹的聚焦边框与 API Key 一致。
- **接入与交接资料。** 更新用户说明、Qwen 配置与复刻参考、模板说明、handoff 和核验记录，明确协助配置的助手与实际聊天后端的区别，并补充其他后端的适配路线。

原有本地 SVG 导入／受限轻摇、五套预设主题、Fish／本地语音、七海欢迎图联动等继续保留。自定义 SVG 不自动获得口型、表情或 Mesh／Live2D 能力。

## 接入范围说明补充

奶绿当前内置并验证的是 Hermes 接入。其他 Agent 或模型服务可根据其开放接口开发适配，但本版尚未提供这些适配，不能仅通过替换连接地址直接使用。你可以把接入说明交给自己常用、具备本机操作能力的 AI 助手协助配置；协助者不必是 Hermes。

本次文档补充列出本地协议桥与新增后端适配器两条开发路线，以及连续会话、取消、审批和语音控制验收要求。其他后端仍未适配／验证，不新增兼容性承诺；软件版本和三个平台安装包保持不变，仅更新接入资料与 handoff。

## 下载与接入

macOS 使用 arm64 App ZIP；Windows x64 选择 portable EXE 或完整目录 ZIP，每个平台只运行一份。应用包同时配套 `MilkyGreen-0.7.49-handoff.zip`。文件、大小与哈希见同目录 README、manifest 和校验文件。

先读 [用户接入说明.md](https://github.com/tosya301/milky-green-desktop/blob/v0.7.49/docs/v0.7.49/用户接入说明.md)，由 Agent 配置则转交 [AGENT-HANDOFF.md](https://github.com/tosya301/milky-green-desktop/blob/v0.7.49/docs/v0.7.49/AGENT-HANDOFF.md)。文字需要用户已有 Hermes Sessions／Runs API；在线试听不需要 Hermes 或 ASR；麦克风需要本地 ASR，VoxCPM2 需要用户自行准备环境、模型和参考音频。应用不会附带开发者的任何账号、Key、Workspace、个人音色、参考录音、聊天或缓存。

原有通用 helper 保留预览／`--apply`、默认或命名 profile、direct／shared 模式；不创建 profile、不迁移网关、不启动服务。模板使用占位符，合并配置时保留现有用户设置。Qwen 的字段与复刻步骤已并入 handoff，无需为它安装本地 TTS 模型。

## 已知边界

网易云是 macOS 实验功能，进度拖动、绝对音量及部分控制不可用，功能完整度不与 Spotify 等同。Apple 降音乐可能影响其他系统音频并改变回复听感；Windows 尚未提供对应模式。在线服务的价格、额度、音色生命周期以各提供方当前规则为准，本资料不承诺永久免费或永久可用。

本次提供运行软件和接入资料，不另附完整开发源码包。应用中保留第三方许可与所需的对应源码入口；新增角色或播放器仍需匹配源码和开发工作。角色图像完整来源／再分发授权材料缺口仍如实记录在随包 `licenses/DISTRIBUTION-NOTICES.md`，该记录本身不是授权证明。
