# 奶绿桌面公共测试版 0.7.4

奶绿是一个可拖动、缩放的桌面伴侣：连接你自己的 Hermes profile，在聊天面板中对话，使用在线或本地语音，并按喜好更换 SVG 立绘与界面配色。

这是供体验和反馈的公共测试版，提供应用包与接入资料，本次不发布完整开发源码。**Windows 包尚未在 Windows 宿主实际运行验收。**

## 本版提供

- 桌面立绘拖动、缩放与聊天面板，连接自己的 Hermes 默认或命名 profile；支持本机环境及 Windows 接入 WSL 的配置方式。
- Fish Audio 在线语音：自行提供 Key 和有权使用的 Voice ID，可先独立试听；也可配置本地 VoxCPM2，麦克风功能另需本地 ASR。
- 本地 SVG 选择、检查、应用、取消与恢复默认。识别到受支持的原有轻摇时可控制开关和幅度；自定义 SVG 不自动获得口型或表情。
- 五套配色，包含 **Nana7mi**；选择后即时保存，配色不会替换立绘。
- 已应用且内容匹配的七海 SVG 可联动欢迎问号图与 `NANA7MI` 字标，恢复默认后还原。文件改名可用，主题不影响识别，名字、签名、头像与聊天身份保持独立。七海 SVG 不随包提供。

应用不附带 Hermes、Python 环境、模型、参考音频、密钥或个人配置。Hermes 接入要求其任务、会话与流式事件接口，不能直接换成任意 OpenAI 兼容端点。本版接受本机回环 API 地址；具体 profile、认证和 WSL 配置请按 handoff 对照现有环境。

## 已验证与限制

- 本轮指定 8 个测试文件聚合 **105 项通过，0 失败、0 跳过**，没有重跑全应用回归。
- 欢迎页面浏览器检查覆盖五套主题、两种尺寸、七海与默认状态，共 20 组；布局、原字标字体和默认恢复通过。
- Mac 源码应用与最终 App 各通过本轮 8 组隔离原生欢迎图检查，包含内容识别、改名、主题独立、草稿取消、用户名字、实际退出重启、默认恢复和同名异内容排除。测试未调用真实 Agent、Fish、音频或麦克风。
- 两平台包已通过架构、白名单、资源引用与哈希检查；Mac App ZIP、Windows 便携 EXE 与目录 ZIP、handoff 均完成回解比对。Windows 宿主启动、声卡、麦克风与多屏尚未实测。

升级保留已有配置。反馈请提供系统版本和复现步骤，不上传 Key、`.env`、完整 profile 或聊天记录。

这是非官方粉丝项目，角色、图像、声音等素材不随代码获得统一授权；第三方许可随应用提供。问号 PNG 随包提供，由 imagegen 去底生成，并非逐像素无损处理。请使用自己有权使用的 SVG 和参考音频。
