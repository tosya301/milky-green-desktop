# 奶绿 0.7.77

Mac 与 Windows 版本统一为 **0.7.77**，相比上一公开版本 **0.7.49** 汇总近期更新。**Windows 仍为测试版，尚未完成实机验收。**

- 新增奶白、奶黑、奶小绿女仆装及可保存的眼镜开关；完善头部跟随、呼吸与表情，补齐奶白／奶黑／泳装的点击回弹。
- 改善待机／活动帧率调度、WebGL 恢复、拖动和大尺寸立绘；新增浅深模式、跟随系统及新的 DIY 随机配色。
- 新增 Windows 网易云 SMTC 测试接入，完善 Spotify 新旧 Hermes 插件、Windows 安装及 Python 兼容；Mac 网易云模式控制同步改善。
- Fish Audio 新增 Drama 3，保留已有声音选择。
- 更新用户接入与 Agent handoff，新增 **VoxCPM2 性能优化指南**；附带可选的公开角色参考（Markdown／V2 JSON／PNG），不新增 App 导入功能。
